# Support

## Using ingresso

| You want to…                     | Do this                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Fix a wrong app link or name     | Edit the tile from your dashboard.                                                                                       |
| Ask a general question           | Open a [discussion](https://github.com/QuinntyneBrown/ingresso/discussions) or email hello@ingresso.dev.                 |
| Report a code of conduct concern | Email conduct@ingresso.dev.                                                                                              |
| Report a bug in the app          | Open an [issue](https://github.com/QuinntyneBrown/ingresso/issues) with steps to reproduce and any reference code shown. |
| Request a feature                | Open an [issue](https://github.com/QuinntyneBrown/ingresso/issues) describing who it helps.                              |
| Report a security issue          | Follow [SECURITY.md](SECURITY.md). Don't open a public issue.                                                            |

## Working on the code

Start with the [README](README.md), then [CONTRIBUTING.md](CONTRIBUTING.md) and [AGENTS.md](AGENTS.md).
Search existing issues before opening a new one.

## Response times

ingresso is run by volunteers. We read every issue and message, but can't promise a response time.
