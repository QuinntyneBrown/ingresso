A table shows comparable records, such as an admin list of users. Put `ig-table` on a native `<table>` and wrap it in `ig-table-wrap`, which scrolls the table inside itself on phones instead of the page; give the wrap a `label` to make it a named, keyboard-scrollable region. Name the table with a `<caption>` (it may be `visually-hidden`) and give header cells `scope="col"`. `th[ig-sort-header]` makes a column sortable: it wraps the label in a button, sets `aria-sort` and draws the direction arrow; bind `[(sort)]`. Rows tint on hover and when `aria-selected="true"`. `.num` right-aligns numbers with tabular figures, `.mono` sets monospace, and `.row-actions` appear on row hover or focus, and always on touch screens.
