### Best practices

#### Do

- Give every table a caption and `scope="col"` header cells.
- Right-align numbers with the `num` class.
- Keep the table in `ig-table-wrap` so it scrolls inside its frame on phones.

#### Don't

- Don't use a table for layout or for a single column of items; use a list.
- Don't let a wide table force the whole page to scroll sideways.
