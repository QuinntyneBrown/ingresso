The layout bar is the banner shown while the dashboard is in edit mode. It is a polite `role="status"` region: the message says what the mode does ("Drag a tile to move it, or drag its corner to resize it. Changes save as you go.") and the projected actions follow, Reset layout as a ghost `sm` button and Done as the one primary `sm` button. Edits save as they go, so Done only leaves the mode. `unavailable` explains that the window must be at least 1024 pixels wide to edit the layout and hides the actions.
