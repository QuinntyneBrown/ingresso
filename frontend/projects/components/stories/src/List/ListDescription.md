A list is a vertical run of items with a title and a meta line, on native list markup: `<ul ig-list>` holding `<li ig-list-item>` rows. The `simple` variant draws divided rows (`surface` puts them on a flush card); the `catalog` variant draws separate bordered rows with an icon (`[slot=media]`) and an action (`[slot=action]`), as in the directory of apps to add. `interactive` highlights a simple row on hover.
