Input styles the native `input`, `textarea` and `select` so forms bind to them directly. Set `aria-invalid="true"` for the invalid state; `disabled` greys it out and `readonly` sinks an input or textarea. Add the class `input--sm` or `input--lg` for the small or large size. A select draws its chevron in CSS and keeps the native picker; a textarea is at least 2.5 rows tall and resizes vertically.
