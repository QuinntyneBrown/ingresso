Pagination moves between pages of a long list or table: a `nav` landmark labelled "Pagination" with labelled previous and next arrows and numbered pages. The current page carries `aria-current="page"`; an arrow with nowhere to go is `aria-disabled`. With more than seven pages it shows the first, the last and the pages around the current one. It emits `pageChange` with the requested page, so `[(page)]` binds both ways. The dashboard shows every tile, so it does not paginate.
