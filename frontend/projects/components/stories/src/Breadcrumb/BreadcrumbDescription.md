A breadcrumb shows where a page sits in a hierarchy: a `nav` landmark labelled "Breadcrumb" with an ordered list of ancestor links and the current page as plain text marked `aria-current="page"`. Pass `items` from the top level down; each crumb takes a `link` (an app route) or an `href`, and the last crumb is the current page. ingresso is mostly flat, so most pages use a back link instead.
