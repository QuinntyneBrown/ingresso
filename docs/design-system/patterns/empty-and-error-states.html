Overview

An empty or failed view is a moment to help. Keep the chrome, say what is happening, offer one action.

When to use

SituationComponent
Nothing yet (first run)Empty state with one primary action
Search or filter matched nothingCompact empty state with Clear
Data failed to loadDanger alert with Try again
No route / no access / server failureError page

Responsive behaviour

Centred and capped at 36ch; full width actions under 640px.

Accessibility

  • Headings are real headings.
  • Retry buttons name what they retry when several are visible.

Content

  • Never blame the person.
  • Offer a way forward every time.
