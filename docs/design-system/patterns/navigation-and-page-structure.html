Navigation and page structure

The shell, page header and how people move around.

WCAG 2.2 AAStatus: stable

Overview

One shell: skip link, app header, <main>, footer. ingresso is flat: the dashboard is home, the directory and settings are one step away with a back link.

When to use

  • Dashboard-first: every page offers a way back to it.
  • Use tabs only for peer views of the same data; otherwise use pages.

Responsive behaviour

Header search wraps under 768px; content is a single column up to 42rem on narrow pages.

Accessibility

  • Landmarks: header, main, footer; one h1 per page.
  • Focus goes to the h1 after route changes.

Content

  • Page titles match the link that opened them.
