Tooltip

A short label that appears on hover and focus.

WCAG 2.2 AAStatus: stable

Overview

For naming icon-only controls. Never put interactive content or essential information in a tooltip.

Anatomy

  1. TriggerAny focusable element
  2. BubbleInverse surface, 12px text
  3. ArrowPoints at the trigger

Variants

Text.

Text
HTML
<div style="padding-top:2.5rem"><button class="btn btn--icon has-tooltip" type="button" aria-label="Edit Linear" data-state="hover"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 20h4L19 9l-4-4L4 16zM13.5 6.5l4 4"/></svg><span class="tooltip" role="tooltip">Edit Linear</span></button></div>

Sizes

Tooltip has a single size.

States

State matrix
VariantHiddenVisible (hover/focus)
Tooltip

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Tooltip reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

role="tooltip" linked by aria-describedby; it supplements, never replaces, the accessible name.

Keyboard

KeyAction
FocusShows
EscHides (WCAG 1.4.13)

Focus

Appears on focus as well as hover; stays while the pointer is over it.

Labelling

The trigger already has aria-label.

Contrast

Text

Motion

Fades in over --duration-fast after 300ms.

Touch

No tooltips on touch: the label must be visible or in the control name.

Content

  • Two to four words, no full stop.
