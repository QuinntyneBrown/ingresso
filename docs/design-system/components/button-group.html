Button group

A set of related buttons joined into one control.

WCAG 2.2 AAStatus: stable

Overview

Use for a small set of mutually related actions or a single-choice toggle (for example theme: System, Light, Dark). Not for primary navigation.

Anatomy

  1. Group containerrole="group" with a label
  2. ButtonsJoined edges, shared radius
  3. Pressed stateAccent tint and border

Variants

Segmented (single choice) is the only variant used.

Segmented
HTML
<div class="btn-group" role="group" aria-label="Theme"><button class="btn" type="button" aria-pressed="true">System</button><button class="btn" type="button" aria-pressed="false">Light</button><button class="btn" type="button" aria-pressed="false">Dark</button></div>

Sizes

Same sizes as Button via btn--sm.

Small
HTML
<div class="btn-group" role="group" aria-label="Density"><button class="btn btn--sm" type="button" aria-pressed="true">Comfortable</button><button class="btn btn--sm" type="button" aria-pressed="false">Compact</button></div>

States

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Button group reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

role="group" with an accessible name; each button is a toggle using aria-pressed.

Keyboard

KeyAction
TabMove between buttons
Space, EnterPress the focused button

Focus

Same ring as Button; the pressed button raises above its neighbours so the ring is never clipped.

Labelling

The group has aria-label; buttons have visible text.

Contrast

Pressed label

Motion

Colour transition only.

Touch

Each segment meets 24px; use md on phones.

Content

  • Two to four short options.
  • Labels are nouns or adjectives of the same kind.
