Tile grid

The 12-column grid that places dashboard tiles where the person puts them, and lets them move and resize tiles in edit mode.

WCAG 2.2 AAStatus: stableLibrary: ig-tile-grid

Overview

Each tile occupies a rectangle of cells: a column, a row, a column span and a row span. The grid never moves a tile the person did not move. A destination that overlaps another tile is refused, with no push, swap or compaction. Ported from qbc-grid (MIT); see ADR 0010. Requirements: L2-009, L2-016, L2-017, L2-042, L2-051, L2-053, L2-054.

Anatomy

  1. Grid lines12 columns, 72px rows, edit mode only
  2. CellPlaced by --x, --y, --cols, --rows
  3. Lifted tileFollows the pointer at drag elevation
  4. Drop shadowSnapped destination; refused when occupied
  5. Resize handleBottom-right corner, 44px target

Sizes

Tile spans run from 2 to 12 columns and 1 to 8 rows (L2-051). New tiles take 3 by 2. Tiles of 4 by 3 or more render as large tiles with a description and footer.

Responsive behaviour

From 1024px: 12 columns with saved positions. From 768px to 1023px: two columns in reading order (top row first, then left to right), and tiles of 6 or more columns take a full row. Below 768px: one column. Collapsing never changes or saves the layout, and edit mode is offered only from 1024px.

Theming

Tile grid reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

A list (<ul aria-label="Your apps">) with items in reading order, so DOM order matches visual order at every width. In edit mode the list carries aria-roledescription="dashboard grid" and an aria-describedby link to the key instructions.

Keyboard

KeyAction
TabTile by tile in reading order
Arrow keysEdit mode: move the focused tile one cell
Shift + arrow keysEdit mode: grow or shrink the span by one cell
EscapeCancel a pointer drag or resize

Focus

Focus stays on the moved tile after each change.

Announcements

A polite live region announces each result: "GitHub moved to column 5, row 3.", "GitHub resized to 4 columns by 2 rows.", "GitHub cannot move there. Those cells are occupied."

Contrast

Tile text
Drop shadow border

Motion

The lifted tile follows the pointer. Settling animates over --duration-fast and is removed under reduced motion.

Touch

Editing needs a pointer or keyboard and a window of at least 1024px. Resize handles are 44px targets.

Content

  • Keep DOM order equal to reading order (row, then column).
  • Announcements name the app, then the new column and row counted from 1.
