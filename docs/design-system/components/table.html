Table

Tabular data with sorting and row actions.

WCAG 2.2 AAStatus: stable

Overview

Not used on the dashboard. Use for lists of comparable records, such as an admin list of users. Tables scroll inside their wrapper on phones.

Anatomy

  1. CaptionVisually hidden title
  2. HeaderSunken, scope="col"
  3. RowsHover and selected tints

Variants

Default and sortable.

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Table reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.
