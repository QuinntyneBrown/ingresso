Select

A native dropdown for choosing one option.

WCAG 2.2 AAStatus: stable

Overview

Use the native select for short lists. If the list is long or searchable, use a combobox.

Anatomy

  1. ContainerSame height as Text field
  2. ChevronDrawn in CSS; inherits colour

Variants

Native.

Default
HTML
<div class="field"><label class="field__label" for="s2">Sort by</label><select class="select" id="s2"><option>Recently opened</option><option>Name</option></select></div>

Sizes

Same sizes as Text field.

Small, medium
HTML
<div class="stack stack--sm"><select class="select input--sm" aria-label="Small"><option>Small</option></select><select class="select" aria-label="Medium"><option>Medium</option></select></div>

States

State matrix
VariantDefaultFocusInvalidDisabled
Select

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Select reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.
