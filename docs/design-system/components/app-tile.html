Overview

Large tiles (the three most recently opened) show icon, name, address, description and an "Opened … / Open" footer. Small tiles show icon, name and address. In edit mode the tile is no longer a link: it shows a drag handle and an Edit button. Implemented as ig-app-tile.

Anatomy

  1. IconInitial on the app colour
  2. NameGeist 600
  3. AddressGeist Mono, muted
  4. Footer (large)Opened time and Open cue

Variants

Large, small, highlighted, editing, dragging.

Responsive behaviour

Under 768px tiles are two per row (large tiles full width); from 768px six columns; from 1024px twelve, with large tiles spanning four and small three.

Theming

App tile reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

A single link (<a target="_blank" rel="noopener noreferrer">) wrapping the content. In edit mode: a movable, resizable item with a button; arrow keys move it and Shift + arrow keys resize it.

Keyboard

KeyAction
TabFocus the tile (or its Edit button in edit mode)
EnterOpen the app in a new tab
Space (edit mode)Lift or drop the tile
← ↑ → ↓ (lifted)Move the tile
Esc (lifted)Cancel the move

Focus

The ring surrounds the whole tile.

Labelling

Link name is "name, address"; opens in a new tab is conveyed by an off-screen hint. Edit button: "Edit Figma".

Contrast

Name
Address
Highlighted edge
Dragging edge

Motion

Hover lifts 1px; dragging uses shadow-4 and a 1° tilt; both stop under reduced motion.

Touch

Tiles are well over 44px tall; drag handles are 24px with a larger hit area.

Content

  • Names are the product's own name, not a URL.
  • Addresses omit the scheme.
