Checkbox

Choose zero or more options.

WCAG 2.2 AAStatus: stable

Overview

Use for independent options. For exactly one of several, use a radio group; for an on/off setting that applies immediately, use a switch.

Anatomy

  1. Box20px, 2px radius
  2. LabelClickable; describes the option
  3. Description (optional)Small text under the label

Variants

Single, group, and group with a hint below the choices ({id}-help, describing the group).

Single
HTML
<label class="choice"><input type="checkbox" checked><span class="choice__text">Open apps in a new tab</span></label>
Notify me
Group
HTML
<fieldset><legend>Notify me</legend><label class="choice"><input type="checkbox" checked><span class="choice__text">When I am offline</span></label><label class="choice"><input type="checkbox"><span class="choice__text">When an app moves</span></label></fieldset>
ConsentOnly for apps you run yourself. People are never asked what it can see.
Group with hint
HTML
<fieldset aria-describedby="fp-help"><legend>Consent</legend><label class="choice">…</label><span class="field__help" id="fp-help">Only for apps you run yourself.</span></fieldset>

Sizes

Checkbox has a single size.

States

State matrix
VariantUncheckedHoverFocusCheckedIndeterminateDisabled
Checkbox

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Checkbox reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

Native checkbox; groups use <fieldset> and <legend>.

Labelling

The wrapping label is the name; the group legend names the group.

Motion

Touch

The whole label row is the target (min 24px, 44px recommended).

Content

  • Labels are positive statements: "Open apps in a new tab".
