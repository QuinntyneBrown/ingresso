Breadcrumb

Shows where the page sits in the hierarchy.

WCAG 2.2 AAStatus: stable

Overview

ingresso is flat, so pages use a back link instead. Breadcrumbs are for deeper structures.

Anatomy

  1. AncestorsLinks
  2. Current pagearia-current="page", not a link
  3. SeparatorCSS slash

Variants

Full.

  2. Directory

Full
HTML
<nav aria-label="Breadcrumb"><ol class="breadcrumb"><li><a href="#">Apps</a></li><li><a href="#">Directory</a></li><li aria-current="page">Asana</li></ol></nav>

Sizes

Breadcrumb has a single size.

States

Links use Link states; the current item is plain text.

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Breadcrumb reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.
