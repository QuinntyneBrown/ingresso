App icon

A coloured rounded square with the app's initial.

WCAG 2.2 AAStatus: stable

Overview

Stands in for an app's own icon so every tile has a recognisable mark. The colour is the person's choice, from the app-colour tokens.

Anatomy

  1. SquareRounded 8px or 12px
  2. InitialWhite, first letter

Variants

Apps in the sample.

Sizes

Medium and large.

States

App icons are decorative and have no states.

Responsive behaviour

Fixed size: 40px (medium) and 56px (large).

Theming

App icon reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.
