Toast

A short message that confirms an action and fades away.

WCAG 2.2 AAStatus: stable

Overview

Toasts confirm without interrupting: "Linear added", "Slack removed — Undo". Errors persist until dismissed. Rendered by ToastService into a ToastRegion.

Anatomy

  1. IconTone
  2. Title and textWhat happened
  3. Action (optional)Undo, Retry
  4. DismissLabelled close

Variants

Four tones, with an action.

Responsive behaviour

Full width at the bottom on phones; stacked, newest on top, from 768px.

Theming

Toast reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Content
