Sizes

Error page has a single size.

States

Error pages have no interactive states beyond their action.

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Error page reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.
