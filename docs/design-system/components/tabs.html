Tabs

Switch between related views of one page.

Overview

Not used in the current mocks. Use when one page has two to five peer views of the same data.

Anatomy

  1. Tab listScrolls horizontally if needed
  2. Tab44px tall
  3. Indicator2px accent bar on the selected tab

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Tabs reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility
