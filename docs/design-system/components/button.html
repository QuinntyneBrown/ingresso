Button

Buttons trigger actions: add an app, save, delete.

WCAG 2.2 AAStatus: stable

Overview

Use a button for something that does; use a link for somewhere that goes. One primary (vermilion) button per view: Add app in the header, Save changes in a form. Danger is for destructive confirmation only.

Anatomy

  1. Leading icon (optional)20px, inherits colour
  2. LabelVerb phrase, sentence case
  3. Container40px tall, 8px radius, 16px padding

Variants

Five variants; choose by importance, not decoration.

Primary, secondary, ghost, link, danger
HTML
<div class="cluster"><button class="btn btn--primary" type="button">Add app</button><button class="btn " type="button">Edit layout</button><button class="btn btn--ghost" type="button">Reset layout</button><button class="btn btn--link" type="button">Brand guide</button><button class="btn btn--danger" type="button">Delete Linear</button></div>
Icon only (needs a label)
HTML
<div class="cluster"><button class="btn btn--ghost btn--icon" type="button" aria-label="Edit Linear"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 20h4L19 9l-4-4L4 16zM13.5 6.5l4 4"/></svg></button><button class="btn btn--icon" type="button" aria-label="Close"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M6 6l12 12M18 6 6 18"/></svg></button></div>
Block (full width)
HTML
<button class="btn btn--primary btn--block" type="submit">Sign in</button>

Sizes

Three sizes; md is the default.

Small, medium, large
HTML
<div class="cluster"><button class="btn btn--sm" type="button">Small</button><button class="btn " type="button">Medium</button><button class="btn btn--lg" type="button">Large</button></div>

Responsive behaviour

Fluid: the component fills its container and needs no breakpoint of its own. Verified at 360, 768 and 1280px.

Theming

Button reads semantic tokens only (listed under Tokens), so it follows the theme without extra CSS. To re-theme it, override its component tokens or the semantic tokens on a [data-theme] ancestor.

Accessibility

Role and pattern

Native <button>. Toggle buttons add aria-pressed (Edit layout); disclosure buttons add aria-expanded.

Keyboard

KeyAction
Tab / Shift+TabMove focus to and from the button
Enter, SpaceActivate

Focus

A 2px accent ring with a 2px offset (--shadow-focus) on every variant; never removed.

Labelling

Visible text, or aria-label for icon-only. Loading keeps the label in the DOM and sets aria-busy="true" plus disabled so it cannot be submitted twice.

Contrast

Label on primary
Label on danger
Secondary edge

Motion

Colour changes in --duration-fast; the 1px press shift is removed under reduced motion.

Touch

40px tall by default; use btn--lg (48px) for primary actions on phones.

Content

  • Start with a verb: Add app, Save changes, Delete Linear.
  • Sentence case, no full stops.
  • Name the object in destructive buttons: "Delete Linear", not "Delete".
