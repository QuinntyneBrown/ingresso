Theming

Light and dark from roles, plus a path for brand themes.

Overview

Light is :root. Dark is [data-theme="dark"] and, when the OS prefers dark and the page has not forced light, the same values under prefers-color-scheme. Each block sets color-scheme so native controls and scrollbars follow.

Token tiers

TierPrefixWho uses it
Primitive--palette-*, --app-color-*, --font-*Semantic tokens only
Semantic--color-*, --text-*, --space-* …Components and pages; themes override this tier
Component--btn-*One component, aliasing a semantic token

How dark differs

  • Surfaces get lighter as they rise (canvas < surface < raised).
  • Vermilion lightens to a salmon so it keeps 4.5:1 against dark surfaces; the label on it flips to dark.
  • Status backgrounds are deep tints with light text.

Consuming tokens.json

tokens/tokens.json is a DTCG export generated from tokens.css (tokens_to_json.py): $type, $value, aliases as {group.token}, dark overrides under $extensions. Regenerate it after any token change; never edit it by hand.

Usage

  • The theme toggle sets data-theme on html; the choice is a per-viewer convenience.
  • Test every change in both themes and with prefers-contrast: more.
