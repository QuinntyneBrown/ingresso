Foundation · Shape

Shape

Five radii and two border widths, scaled to the size of the thing.

WCAG 2.2 AA
  • Overview
  • Radii
  • Border widths
  • Usage
  • Tokens

Overview

Radius grows with the element: inputs and buttons use --radius-md, tiles and dialogs --radius-lg, bottom sheets --radius-xl, avatars and badges --radius-full. App icons use --radius-md (small) and --radius-lg (large).

Radii

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

Border widths

TokenUse
--border-width-hairlineTile, card and input edges
--border-width-thickSelected swatch, focus emphasis

Usage

  • Nested radii: the inner radius is the outer radius minus the padding.
  • Do not mix more than two radii in one component.

Tokens

Every --radius-*, --border-width-* token in tokens/tokens.css (8). Values are live for the current theme.
