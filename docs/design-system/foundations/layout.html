Overview

Mobile first. Columns, gutters and margins change at the breakpoints through tokens, so the dashboard reflows without a component knowing the width. Tiles span the 12-column grid: three large tiles of 4, small tiles of 3.

Breakpoints, columns, gutters, margins

BreakpointFromColumnsGutterMargin
Phone0416px16px
Tablet (--layout-breakpoint-md)768px824px32px
Laptop (--layout-breakpoint-lg)1024px1232px48px
Desktop (--layout-breakpoint-xl)1280px1232px48px

The tile grid itself uses 2, 6 and 12 columns so recent tiles stay 1, 3 and 3 across.

Usage

  • Use .container, .grid, .stack and .cluster instead of ad hoc flex rules.
  • No horizontal page scroll at 360px; tables scroll inside .table-wrap.
