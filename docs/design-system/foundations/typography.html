Typography

Geist for words, Geist Mono for addresses, with twelve role shorthands.

WCAG 2.2 AA
  • Overview
  • Role specimens
  • Families
  • Measure and line height
  • Usage
  • Accessibility

Overview

Geist, set lowercase and tight for the wordmark and headings (600 weight, −4.5% tracking). Body copy is Geist Regular at 16px. Geist Mono is only for addresses and technical values, so people can tell where a tile goes. Both are self-hosted (ADR 0005) as variable fonts.

Role specimens

Use a role shorthand (font: var(--text-h2)) instead of setting size, weight and line height separately.

Measure and line height

Prose is capped at --layout-measure (65ch). Body line height is 1.5; headings are tighter (1.2 and 1.3). Nothing is set below 12px (--font-size-xs).

Usage

  • Sentence case everywhere except the lowercase wordmark.
  • Tile names use --text-h4 (large tiles) or --text-label (small); addresses use --text-code in --color-fg-muted.
  • Numbers in counts and times use font-variant-numeric: tabular-nums.

Accessibility

Text uses rem so browser zoom and font-size settings scale it. Body stays at 16px; contrast of muted and subtle text is checked on every surface (see Color).
