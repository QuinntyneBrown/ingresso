Accessibility

The WCAG 2.2 AA commitments behind every component.

Overview

ingresso commits to WCAG 2.2 AA. These are the commitments every component page documents under its own Accessibility section.

Commitments

  • Text contrast 4.5:1; UI edges and focus 3:1, in both themes (checked by check_contrast.py).
  • Everything is operable by keyboard with a visible focus ring (--shadow-focus), and focus order follows reading order.
  • Targets are at least 24px, and 44px for primary mobile actions (2.5.8).
  • Dialogs trap focus, make the page inert, close on Escape and return focus.
  • Toasts live in a polite region; errors use role="alert" and never auto-dismiss.
  • Colour is never the only cue.
  • Moving and resizing tiles have a keyboard path; dragging is never required (2.5.7).
  • Reduced motion is honoured through tokens.
  • Content reflows at 320px and at 400% zoom.

Testing procedure

  • Tab through each page, dialog and toast in light and dark.
  • Run the contrast checker after any token change.
  • Use a screen reader on the dashboard: tiles read as "name, address, link, opens in a new tab".

Component contract

A component page is done when it names its ARIA pattern, keyboard map, focus behaviour, labelling, contrast pairs, motion and touch behaviour.

Tokens

Every --target-*, --focus-ring-*, --control-height-* token in tokens/tokens.css (7). Values are live for the current theme.
