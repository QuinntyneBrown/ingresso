Overview

ingresso is a warm, quiet room with one bright doorway. Vermilion is the doorway: primary actions, focus, the mark. Ink is the door: text and the wordmark. The canvas is a warm off-white behind every tile; hairlines hold quiet structure. Status colours are deep tints with a dot or icon and a word, never colour alone.

Primitive ramps

Primitives are raw values. Components never read them; semantic tokens alias them. Ramps are shown in the current theme and do not change between themes.

Usage

  • Text colours come from --color-fg-*; never put --color-accent text on a tinted surface without checking the pair below.
  • Use --color-accent for the one primary action per view, selection and focus. Everything else is ink on canvas.
  • Never use colour alone: badges carry a dot and a word, errors an icon and text, links an underline.
  • Hexadecimal values exist only in tokens/tokens.css.

Adding a brand theme

Add a [data-theme="name"] block that overrides semantic tokens only, then add its pairs to tokens/contrast-pairs.json and run check_contrast.py. Do not copy component CSS.

[data-theme="harbour"] {
  --color-accent: var(--palette-green-700);
  --color-accent-hover: var(--palette-green-900);
}
