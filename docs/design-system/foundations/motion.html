Foundation · Motion

Motion

Short, purposeful transitions that disappear under reduced motion.

WCAG 2.2 AA
  • Overview
  • Durations
  • Easings
  • Choreography
  • Reduced motion
  • Tokens

Overview

Motion confirms, never decorates. Hovering a tile lifts it 1px in --duration-fast; dialogs and sheets enter in --duration-slow; a moved tile settles with the standard easing. Skeletons shimmer once per --duration-shimmer.

Durations

Easings

Choreography

  • Enter with --ease-enter, exit with --ease-exit; exits are shorter than entries.
  • Only animate transform, opacity and colour.
  • A dropped tile settles in --duration-base; other tiles slide to make room in the same duration.

Reduced motion

Under prefers-reduced-motion: reduce the tokens set every duration to 0.01ms, so components need no extra media queries and nothing flashes. Toast timers still pause on hover and focus.

Tokens

Every --duration-*, --ease-* token in tokens/tokens.css (12). Values are live for the current theme.
