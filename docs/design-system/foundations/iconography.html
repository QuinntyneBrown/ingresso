Iconography

A small stroke icon set and the ingresso mark.

WCAG 2.2 AA
  • Overview
  • Icons used in the mocks
  • Sizes

Overview

Inline SVG on a 24-unit grid, 2px stroke, round caps, currentColor. Decorative icons carry aria-hidden="true"; icon-only buttons carry an aria-label.

Icons used in the mocks

Logo and mark

The logo is a vermilion arch with an ink panel swung open; the doorway is cut from negative space so it takes any background. Use the light logo on light surfaces and the dark logo on dark ones.

Usage

  • Pair an icon with a text label wherever space allows.
  • Do not use colour alone to distinguish icons.
