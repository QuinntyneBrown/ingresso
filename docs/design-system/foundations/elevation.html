Elevation

Hairlines at rest, shadow only when something lifts.

WCAG 2.2 AA
  • Overview
  • Shadow levels
  • Surface hierarchy
  • Z-order
  • Usage
  • Tokens

Overview

Tiles rest on one hairline and a whisper of shadow; elevation appears only when something is lifted: hover, a menu, a dialog, a tile being dragged. In dark, surfaces get lighter as they rise and shadows get darker.

Shadow levels

--shadow-1
--shadow-2
--shadow-3
--shadow-4
LevelUse
--shadow-1Tiles and cards at rest
--shadow-2Hovered tiles, raised cards
--shadow-3Menus, popovers, toasts
--shadow-4Dialogs, sheets, a dragged tile
--shadow-focusFocus ring (two rings: offset and accent)

A component never sets a raw z-index.

Usage

  • Do not add shadows to flat elements to make them "pop"; use border and canvas contrast.
  • A dragged tile uses --shadow-4 and a 1° tilt; a drop target uses a dashed accent border.

Every --shadow-*, --z-* token in tokens/tokens.css (15). Values are live for the current theme.
