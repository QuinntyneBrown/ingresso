Brand guide

The rules ingresso is drawn by.

Logo and mark

A vermilion arch with an ink panel swung open. The doorway is cut from negative space, so it takes any background.

Colour

  • VermilionThe doorway. Primary actions, focus, the mark.
  • InkThe door. Text, icon backgrounds, the wordmark.
  • CanvasThe room. Canvas behind every tile.
  • LineHairlines, dividers, quiet structure.

Type

Every app, one door.

Headings and the wordmark use Geist 600, lowercase and tight. Addresses use Geist Mono so people can tell where a tile goes.
