## 01-dashboard-before
This is your dashboard, with the apps you already use. Say you want to add one more.

## 02-add-app-dialog
Choose Add app in the header. A small dialog asks for a name and an address. Only those two are required.

## 03-address-missing
Give the app a name and forget the address, and ingresso tells you exactly what is missing. Focus stays in the dialog, so you can fix it right away.

## 04-address-fixed
Type the web address, pick a colour you like, and save.

## 05-new-tile-and-toast
The new tile lands in the first free space, and a message confirms it. If you ever add the same address twice, ingresso warns you first. One dialog, two fields, and your app is on the door.
