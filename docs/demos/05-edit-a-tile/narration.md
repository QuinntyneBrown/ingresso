## 01-edit-layout-mode
Apps change, and your tiles should keep up. Turn on edit layout, and every tile gets an Edit button.

## 02-edit-dialog
Choose Edit, and a dialog opens with the app's current name, address, description and colour, ready to change.

## 03-changes-made
Rename it. Pick a new colour. If something is not valid, ingresso tells you which field, and nothing is saved until it is right.

## 04-saved-with-toast
Save, and the tile updates in place, in the same spot and the same size, with a message to confirm. Cancel or press Escape instead, and nothing changes. Edit it once, and it is right everywhere.
